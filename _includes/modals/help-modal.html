PANDUAN WOIPS
🌟 Selamat Datang di WOIPS!

WOIPS adalah platform terintegrasi dengan 3 aplikasi dalam 1 untuk membantu persiapan OSN IPS kamu.

OLYMPEDIA
OLYMAP
OLYMNOTE

Semua data disimpan di localStorage browser kamu (privat)

Bisa digunakan offline setelah pertama kali buka (PWA)

Gratis selamanya untuk pejuang OSN IPS

📚 OLYMPEDIA - Gudang Materi

✨ Fitur:

  • Preview Google Drive langsung di aplikasi
  • Bookmark materi favorit
  • Tracking progress baca (halaman terakhir)
  • Filter per kategori (Geografi, Ekonomi, dll)
  • Pencarian materi

📖 Cara Penggunaan:

  1. Klik materi yang ingin dibaca
  2. Viewer Google Drive akan terbuka
  3. Isi halaman terakhir yang dibaca
  4. Klik SIMPAN untuk menyimpan progress
  5. Klik icon bookmark untuk menyimpan ke favorit
Materi diambil dari sumber publik untuk pendidikan.
🗺️ OLYMAP - Roadmap Belajar

✨ Fitur:

  • To-do list interaktif per topik
  • Pin prioritas (tetap di atas)
  • Tracking progress per kategori
  • Target deadline belajar
  • Animasi confetti saat selesai

📖 Cara Penggunaan:

  1. Pilih tab kategori (Geo/Eco/His/Soc)
  2. Klik [+] untuk tambah roadmap baru
  3. Centang kotak jika materi sudah dipahami
  4. Klik card untuk lihat detail materi
  5. Pin materi prioritas agar selalu di atas
📝 OLYMNOTE - Glosarium Istilah

✨ Fitur:

  • 200+ istilah OSN IPS + penjelasan
  • Filter per kategori
  • Pencarian cepat
  • Copy teks ke clipboard
  • Bookmark istilah penting

📖 Cara Penggunaan:

  1. Gunakan search untuk mencari istilah
  2. Klik filter untuk memfilter kategori
  3. Klik card untuk lihat detail lengkap
  4. Klik icon bookmark untuk menyimpan
  5. Klik icon trash untuk menghapus
